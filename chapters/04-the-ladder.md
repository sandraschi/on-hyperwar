# IV. The Ladder (control rungs over kill chains, Bands I-VI)

## Thesis

44 rungs (target, mirror the sister book's count only if earned) ordered
by reversibility of human control over killing - from assisted targeting
to delegated release to autonomous campaigning. Each rung: dated public
instance or `[construction]`.

## Bands (draft)

- I Assisted perception (human decides, machine sees).
- II Supervised release (human approves each strike, machine executes).
- III Batch approval (human approves envelopes, machine picks inside).
- IV Delegated defense (machine releases without asking: C-RAM, Aegis-like).
- V Autonomous hunting (machine finds and kills in a box, human watches).
- VI Campaign delegation (objectives set, conduct machine-planned).
