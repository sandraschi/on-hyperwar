# Contributing — on-hyperwar

## System of record

GitHub Issues (like the sister repo). Discord/forum threads are front-end
only and must be mirrored into the relevant Issue before counting as resolved.

## Rule 1 — Observability (per rung)

Name the rung number, what's wrong with its current evidence or wording,
and the concrete change. Every rung must resolve to a dateable, checkable
public fact: dated strike/incident reporting, procurement records, unit
announcements, manufacturer datasheets, official statements. Quoted public
speech for intentions. Secret programs do not exist for this book until
publicly evidenced.

## Rule 2 — Hazard (HARD, non-negotiable)

This book describes control over violence. It must never facilitate it.

**In scope:** institutional facts (who fields what, when, under whose
authority), governance criteria (approval gates, export regimes, hotlines,
treaty language), control failures with dates.

**Out of scope, always cut on sight:** tactics/techniques/procedures,
build or modification guides, procurement how-tos (where to source what),
targeting detail, frequencies/protocols that aid jamming or evasion,
code, configurations, ranges/payloads beyond what manufacturers publish.
Attention hazards (snuff framing, kill-count scoreboards) need explicit
sign-off like in any other hazard call.

When in doubt, ask: does this paragraph help a principal attach a brake,
or help an operator press an accelerator? Ship only the first.

## Prose

Beats first (3-5 facts per section), ugly draft, 3 AI variants constrained
to the README voice, red-team for flab, read aloud (declaim pipeline),
lore-keep rung numbers and dates. No single-pass AI chapters. Attribute
with `Co-Authored-By:` trailers where model lines survive.

## Definitions

- `[construction]` = asserted, not yet evidenced. Required flag, never silent.
- Thresholds A-E = attachment points with named owners (see Ch VI stub).
- No evidence-by-proximity: a Shenzhen catalog listing is not a fielding.
