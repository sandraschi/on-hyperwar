# Glossary — on-hyperwar

**Status:** definitions only (2026-09-20). Rule 2 HARD applies: institutional facts + governance criteria only. No TTPs, no build guides, no procurement how-tos, no targeting detail, no code. If a definition would help an operator press an accelerator, cut it.

## How to use

One line per term, plain declarative. Manufacturer-published specs only. Link to REFERENCES where a term has a dated exhibit.

## Terms

- **ACR (Advanced Combat Rifle):** US Army program 1989/90 seeking 100% improvement over M16A2. No entrant selected. See [STEYR-ACR].
- **APERS-T:** antipersonnel-tracer artillery category, named only. No ballistics here.
- **AUG:** Steyr AUG, Austrian bullpup rifle fielded 1977. Institutional fact: bullpup that shipped at scale.
- **Bullpup:** rifle layout with action and magazine behind the trigger, shortening overall length. Canonical examples: Steyr AUG (Austria), FAMAS (France), SA80/L85 (UK), Tavor/X95 (Israel), FN F2000 (Belgium), VHS-2 (Croatia), SAR-21 (Singapore), QBZ-95 (China). Definition only.
- **P90:** FN Herstal PDW (Belgium, 1990). Compact layout with top-mounted magazine and downward ejection through the stock. Cultural marker: Henrietta (Gunslinger Girl) carries one, including a stumble-and-reprimand beat about handling. Institutional fact only, no employment detail.
- **Chamber:** part of a firearm that holds the cartridge at firing. Definition only.
- **EW (electronic warfare):** contest over radio-frequency spectrum by jamming, spoofing, or denial. See Ch V fiber-FPV entry.
- **Find/fix:** shorthand for the front of the kill chain: correlate identity (find), determine location (fix). Used in this book as a labor-cost marker, never as workflow.
- **Flechette:** small dart-like kinetic projectile, stabilized in flight. Historical examples: air-dropped Lazy Dog, artillery APERS flechette rounds, Steyr ACR 0.66 g prototype. Inert kinetic unless otherwise prohibited by treaty. No fabrication detail.
- **FPV (first-person view):** drone flown via onboard video link, or via fiber/autonomy when the link is denied. See Ch V.
- **Glock:** Austrian polymer-framed striker pistol, Glock 17 from 1982. Institutional fact: police/military adoption at scale.
- **GNSS:** global navigation satellite system family (GPS, Galileo, etc.). Named only, no frequencies/protocols.
- **LAWS:** lethal autonomous weapon systems, per UN CCW GGE usage. See [CCW26].
- **MEMS:** micro-electromechanical systems, e.g. commercial inertial units. Named only.
- **Muzzle velocity:** projectile speed at barrel exit as published by manufacturer. No load data.
- **OODA:** observe-orient-decide-act loop (Boyd). Method ancestor for speed arguments, critiqued in Ch III. See [BOY86].
- **Rate of fire:** rounds per unit time as published, e.g. cyclic vs sustained. No modification detail.
- **Sabot:** carrier that lets a sub-caliber projectile travel through a larger bore, then separates after exit. Definition only. No materials, dimensions, or fabrication.
- **SSG 69:** Steyr SSG 69 sniper rifle, fielded 1969. Institutional fact: long-serving bolt-action reference.
- **VLA (vision-language-action):** model family mapping images + language to actions, e.g. gimbal/sniper-bench prototypes in Ch V. Named only, no training detail.
